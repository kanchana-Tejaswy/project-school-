# Luma — Ideas Worth Your Attention

Luma is a premium editorial-style blogging website focused on thoughtful stories about technology, creativity, design, culture, productivity, mindset, and learning.

The current implementation is a frontend-focused static website built with HTML, CSS, and JavaScript. The primary application page is `index.html`, with interactive behavior provided by `script.js`.

## Features

- Premium editorial hero section
- Featured story and trending sections
- Editor's selection
- Latest stories with category filters
- Topic exploration
- Editorial principle section
- Newsletter subscription UI
- About section and footer
- Search overlay with client-side search
- Reading progress indicator
- Responsive navigation and layouts
- Light/dark theme persistence
- Smooth anchor navigation
- Scroll reveal animations
- Toast notifications
- Basic email validation
- Keyboard shortcuts for search

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- CSS custom properties
- Intersection Observer API
- Local Storage API
- Google Fonts: DM Sans and Instrument Serif

No frontend framework or backend is required for the current static implementation.
